## 🎮 Project Overview

**RagDoll** is a physics-based Unity project with **online multiplayer support**.  
Watch hilarious ragdoll interactions with friends as you throw, fall, and collide in a shared environment. Built using Unity's physics system and networked with multiplayer functionality.

---

## 🌟 Key Features

- 🤝 **Online Multiplayer Support**  
  Play with friends in real-time across the internet. Watch each other's ragdolls flop around hilariously!

- 🔄 **Realistic Ragdoll Physics**  
  Each limb reacts dynamically using Rigidbody and Collider components.

- 💥 **Force & Collision Interactions**  
  Push, fling, or collapse into others — multiplayer chaos guaranteed.

- 🛠️ **Configurable Joints**  
  Use joint constraints for realistic movement and custom poses.

- 🖥️ **Cross-Platform Ready**  
  Designed for **PC**, **WebGL**, and potentially **Android** (with touch control adaptation).

| Apply Force    | Mouse Click / Keybind  |
| Interact       | `E` or UI Button       |
| Reset Player   | `R`                    |

*(Customizable based on build — update as needed.)*

---

## 🌐 Multiplayer Details

- Connects players over the network using Unity's multiplayer tools (Photon, Netcode for GameObjects, etc.).
- Each player controls their own ragdoll in a shared world.
- Ideal for chaotic fun and testing physics behavior with friends.
